# Three-tier access control

Access is split into three credentials: Master Admin (email + password) for management, Platform password for read-only Viewer access across all Leagues, and Kiosk password to unlock interactive Shot recording on a specific device. We chose this because the table screen must be usable by anyone after a single unlock, while preventing passers-by from recording Shots, and keeping management separate from day-to-day viewing. The alternative (one password for everything, or per-Player login at the table) was too coarse or too slow for casual office play.
